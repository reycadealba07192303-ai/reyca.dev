# Cursor portrait

`reyca-directions.png` was generated with the built-in image generation tool from the supplied portrait.

Prompt: Preserve the woman's identity, natural facial features, black hair, black blazer, white shirt, gray studio background and lighting. Create one square 3 by 3 sprite atlas with equal tiles and no borders or text. Keep head scale, shoulder position and framing consistent. Viewer-relative directions: up-left, up, up-right; left, neutral, right; down-left, down, down-right. Use natural head turns and matching eye gaze.

The avatar uses CSS background positions to show these nine poses. Cursor angles select one of eight directions; the center dead zone, pointer leaving the window, and reduced-motion preferences restore the neutral pose. Touch input does not animate the portrait.
